# Mistwood Residence — Cursor Redesign Pack

Contains six separate UI reference crops, a six-page overview, two asset-pack reference sheets, supplied original property photos, a logo reference, and a ready-to-paste Cursor prompt.

## Important
- UI mockups and asset-pack sheets are **visual references**, not a complete set of independently usable transparent PNG/SVG assets.
- The page crops are from a single generated overview; they are not full-resolution standalone page screenshots.
- Use original property photos for actual room/property content; AI mockups can depict fictional buildings and interiors.
- The logo-reference file may contain a checkerboard baked into the pixels; verify transparency before use.

## Use
1. Extract this ZIP into your project, e.g. `design-reference/`.
2. Open `CURSOR_PROMPT.md`, copy its content into Cursor Agent.
3. Ask Cursor to inspect the existing project before changing files.
